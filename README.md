# 🛒 Shopинг (Django)

**Django** asosida qurilgan oddiy onlayn do'kon (e-commerce) namunasi: mahsulotlar va telefonlar bo'limi.

---

## ✨ Imkoniyatlar

- 📱 **Mahsulotlar** ko'rsatish (`news` app)
- 🗂 **Kategoriyalar:** telefon va boshqalar
- 🎨 **Bootstrap shablonlar**
- 🖼 **Media fayllar**

---

## 🛠 Texnologiyalar

| Texnologiya | Maqsad |
|---|---|
| **Python 3.10+** | Asosiy til |
| **Django** | Veb-framework |
| **SQLite** | Ma'lumotlar bazasi |
| **Pipenv** | Bog'liqliklar |

---

## ⚙️ O'rnatish

```bash
git clone https://github.com/dastonbek8747/shoping.git
cd shoping
pipenv install
pipenv shell
```

---

## ▶️ Ishga tushirish

```bash
python manage.py migrate
python manage.py runserver
```

Brauzerda: `http://127.0.0.1:8000`
